GitHub Repository: https://github.com/Shrikannan8999/campus-cafe

Why was this project built?

During college lunch and recess breaks, campus cafeterias experience massive queues and counter congestion. Students lose valuable time deciding what to eat, verifying prices, and calculating their bill. Campus Cafe solves this by offering a responsive, digital ordering portal where students can view 13 daily cafeteria favorites across Snacks, Meals, and Drinks, search and filter food items, add dishes to their food tray, adjust quantities, see an automatic bill calculation (Subtotal + 5% GST), and receive a simulated order reference number and pickup token for Counter #1.

C. js/script.js (Vanilla JavaScript Logic)

Function / Variable What It Does (Viva Explanation)
menuItems Array of 13 food objects across Snacks, Meals, and Drinks. Each object has id, name, category, price, description, and image.
cart Array of objects currently in the user's food tray: { id, name, price, quantity }.
pastOrders Array of completed order objects saved in LocalStorage.
displayMenu(items) Loops through items using forEach(), dynamically builds HTML cards with template literals, and appends them to #menuGrid. If items array is empty, it displays #noItemsMessage.
applyFilters() Combines active category button and live search text. Filters menuItems using .filter() checking item.category === selectedCategory and name.includes(query).
addToCart(itemId) Uses menuItems.find() to get the dish. Then uses cart.find() to check if it's already in the cart. If yes, increments quantity += 1; if not, pushes new object. Calls updateCartDisplay() and saveCartToStorage().
increaseQuantity(itemId) Finds the item in cart and increases its quantity by 1.
decreaseQuantity(itemId) Finds item index using findIndex(). If quantity > 1, decrements by 1. If quantity === 1, removes it using cart.splice(index, 1).
removeFromCart(itemId) Removes an item completely using cart = cart.filter(item => item.id !== itemId).
clearCart() Prompts user with confirm(), resets cart = [], and updates UI.
updateCartDisplay() Calculates bill: loops through cart, calculates item.price * item.quantity, computes subtotal, tax = subtotal * 0.05 (5% GST), and grandTotal = subtotal + tax. Updates DOM with .toFixed(2). Disables checkout button if cart is empty.
placeOrder() Generates random Order ID (CC-XXXXX) and Token (#T-XXX) using Math.random(). Records order into pastOrders, clears cart, saves to LocalStorage, and opens #orderModal.
saveCartToStorage() Serializes cart to string using JSON.stringify(cart) and writes to localStorage.setItem('campusCafeCart', ...).
loadCartFromStorage() Reads string with localStorage.getItem('campusCafeCart') and deserializes it back to an array using JSON.parse().
renderPastOrders() Iterates over pastOrders array and renders previous order receipts inside the past orders modal.

3. Core Technical Concepts You Must Know

1. What is DOM Manipulation?

The DOM (Document Object Model) is the browser's in-memory tree representation of the webpage. Instead of hardcoding 13 food cards in HTML, JavaScript reads our menuItems array and dynamically generates HTML elements using document.createElement('div'), sets its inner content using template literals, and inserts it onto the screen using menuGrid.appendChild(card).

2. How does LocalStorage work?

localStorage is an HTML5 browser storage mechanism that stores key-value pairs permanently on the user's computer until cleared. Because LocalStorage can only store plain text strings, we use:

  • JSON.stringify(cart): Converts our JavaScript array of objects into a JSON text string before saving.
  • JSON.parse(savedData): Converts the saved JSON text string back into a live JavaScript array when the website opens.

3. How is the bill calculated automatically?

let subtotal = 0;
cart.forEach(function (item) {
  subtotal += item.price * item.quantity; // Sum of price * quantity
});
const tax = subtotal * 0.05;              // 5% College Canteen GST
const grandTotal = subtotal + tax;        // Final total amount
// Display formatted with 2 decimal places:
summaryGrandTotal.textContent = "₹" + grandTotal.toFixed(2);

5. 25 Expected Faculty Viva Questions & Model Answers

Q1: Why did you choose Vanilla JavaScript instead of React or Vue?
"Because this is an academic Continuous Assessment project aimed at mastering fundamental web development principles. Frameworks introduce heavy dependencies and build tooling; writing Vanilla JavaScript demonstrates a solid grasp of core DOM manipulation, event handling, and modern ES6 array methods."
Q2: What is the difference between let and const?
"const is used for variables whose identifier cannot be reassigned, such as DOM references (const menuGrid) and our master menuItems database. let is block-scoped and allows reassignment, which we use for dynamic state like cart and accumulators like subtotal."
Q3: How does the live search work on every keystroke?
"We listen to the input event on #searchInput. Every time a character is typed, applyFilters() runs. It converts the input to lowercase and uses .filter() to check if the food name or description includes the search query."
Q4: What happens if a user clicks '+ Add to Tray' on an item that is already in the cart?
"We use cart.find(item => item.id === itemId). If the item is found, we do not add a duplicate card; instead, we increment its existing quantity property by 1 (existingItem.quantity += 1)."
Q5: How does an item get removed when decreasing quantity?
"Inside decreaseQuantity(itemId), we check if quantity > 1. If so, we decrement by 1. If quantity is currently 1 and the user clicks minus, we call cart.splice(itemIndex, 1) to remove that element from the array."
Q6: What is the purpose of event.target.closest('.category-btn')?
"It implements Event Delegation. Instead of adding separate event listeners to every tab button, we place one listener on the parent container (#categoryTabs). When clicked, .closest() finds the clicked button even if the student clicked on the emoji icon inside it."
Q7: What is the difference between localStorage and cookies?
"LocalStorage provides 5MB of storage per origin and data is never sent to the server with HTTP requests. Cookies are limited to 4KB and are automatically transmitted with every network request, which is unnecessary for purely client-side state."
Q8: Why do we use .toFixed(2) on prices?
"Because JavaScript uses IEEE 754 floating-point math, which can produce numbers like 14.999999999996. .toFixed(2) rounds and formats the number into a clean string with exactly two decimal places, representing Rupees and Paise."
Q9: How do you prevent a student from placing an empty order?
"In updateCartDisplay(), if cart.length === 0, we set placeOrderBtn.disabled = true. Additionally, inside placeOrder(), we have an explicit guard condition: if (cart.length === 0) return;."
Q10: What is CSS Grid and why did you use it for the menu cards?
"CSS Grid is a two-dimensional layout system. We used grid-template-columns: repeat(auto-fill, minmax(260px, 1fr)). This automatically calculates how many 260px cards fit across the available width and stretches them proportionally, creating a responsive grid without manual media queries for each card."
Q11: Why are vector SVG images used instead of standard heavy JPGs?
"SVGs are XML-based vector graphics. They are extremely lightweight (~1.3 KB each), look sharp on any screen resolution, load instantaneously, and work 100% offline without relying on external image CDNs."
Q12: What does document.addEventListener('DOMContentLoaded', ...) do?
"It ensures our JavaScript code does not execute until the browser has fully downloaded and parsed the HTML DOM structure, preventing errors where script attempts to access elements that don't exist yet."
Q13: How does the Order Reference Number get generated?
"Using 'CC-' + Math.floor(10000 + Math.random() * 90000). This generates a pseudo-random 5-digit number between 10000 and 99999 prefixed with 'CC-'."
Q14: How does the Past Orders history work?
"Whenever an order is confirmed, we construct an order record object with the timestamp, token, order ID, items summary, and total amount paid. We unshift() it to our pastOrders array and save it to LocalStorage under campusCafeOrderHistory."
Q15: How is the website hosted and deployed?
"It is hosted on GitHub Pages directly from our repository branch main. Because all file paths are relative and there are zero backend requirements, GitHub Pages serves the static assets immediately over secure HTTPS."
